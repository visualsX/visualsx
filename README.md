# visualsX

Marketing site for visualsX, a product studio that ships MVPs for founders.

Built with Next.js (App Router) and Tailwind CSS v4.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```

## Where things live

- `lib/site.js`: all site copy (services, projects, FAQs, contact details). Edit text here.
- `app/`: pages (home, services, work, about, careers, contact).
- `components/sections/`: page sections. `components/ui/`: shared building blocks.
- `public/clients/`: client logos used in the logo strip and project cards.
